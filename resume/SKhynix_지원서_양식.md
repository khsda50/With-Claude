## 작성 시 유의점 (JD 대조)

JD에서 읽어낸 소구점을 어느 칸에서 증명할지 미리 배분:

| JD 요구 | 증명할 칸 |
|---|---|
| In-house VIP 개발 / 검증 환경 구성 | 경력-담당업무, 경험, 경력기술서 |
| 신규 Protocol·Custom IP UVM Agent A-to-Z | 경험/특허 (`q_chan_vip`), 경력기술서 |
| Code/Functional Coverage Closure | 경력기술서 (정량 수치 필수) |
| Analog-Digital Mixed / Full-Chip Mixed-Level 검증 | 경력-담당업무 |
| 지원 동기 · 이직 사유 | 자기소개서 5-1 |

- 총 분량이 매우 타이트함 (자소서 3,000자 + 경력당 500자). **압축이 이 지원서의 핵심 난이도.**
- 모든 서술 항목은 "무엇을 했다"가 아니라 "없던 것을 세웠다 + 숫자"로 쓸 것.
