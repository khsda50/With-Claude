# 시험 구조와 등급 — 무엇으로 채점되는가

## 1. 시험 흐름

```
① Background Survey   직업 · 거주 형태 · 여가활동 · 취미 · 운동 · 휴가  (문제 출제 범위가 여기서 결정됨)
② Self Assessment     난이도 1~6 자가진단  (실제 출제 난이도 결정)
③ 샘플 문항 청취
④ 1번 문제 = 자기소개
⑤ 본 문항  (보통 12~15문항, 난이도에 따라 다름)
   └ 2번 문제 이후 한 번, 난이도를 조정할 기회가 주어진다
⑥ 종료 (총 약 40분)
```

문항은 **3개씩 묶인 "콤보"** 로 나온다. 난이도 5~6 기준 대략:

| 구간 | 내용 |
|---|---|
| 1번 | 자기소개 |
| 2~4번 | 서베이 콤보 1 (예: 영화 — 묘사 → 습관 → 기억에 남는 경험) |
| 5~7번 | 서베이 콤보 2 |
| 8~10번 | **롤플레이** (상황 주고 질문하기 → 문제 해결 → 관련 경험 말하기) |
| 11~13번 | 서베이 또는 **돌발** 콤보 (은행·교통·날씨·기술 등 서베이에 없던 주제) |
| 14~15번 | 고난도 — 비교, 변화, 사회적 이슈 |

> 시험지 구성은 회차마다 조금씩 다르다. 다만 **"콤보 3문항 = 묘사 / 습관 / 경험"** 패턴은 거의 고정이다.
> 이 패턴을 아는 것만으로 준비량이 1/3로 줄어든다 — `01_템플릿/01_유형별_답변_템플릿.md` 참고.

## 2. 등급 체계

```
NL → NM → NH → IL → IM1 → IM2 → IM3 → IH → AL
                        ↑현재            ↑목표
```

IM 구간이 IM1/IM2/IM3로 나뉘는 건 한국 OPIc의 세분화다. **IM1은 IM 구간의 바닥**이고,
IM3까지는 같은 IM 안에서의 이동, IH는 **레벨 자체가 한 칸 올라가는 것**이다.
4주에 IM3는 충분히 현실적이고, IH는 "잘 되면"의 영역이다. 전략은 **IM3를 확보하고 IH를 노리는 것**.

---

## 3. 채점 기준 4가지 (ACTFL)

채점자는 발음이나 단어 난이도를 보는 게 아니라, 아래 4개를 본다.

| 기준 | 뜻 | IM1의 문제 | IH가 되려면 |
|---|---|---|---|
| **과제 수행 / 기능** | 질문이 요구한 걸 실제로 했는가 | 질문에 답은 하는데 겉만 훑음 | 묘사·서술·비교·설명을 요구대로 수행 |
| **맥락 / 내용** | 얼마나 구체적인가 | "It was good. I liked it." | 언제·어디서·누구와·왜를 스스로 채움 |
| **정확성** | 문법·어휘·발음이 이해를 방해하는가 | 시제 혼동, 단순 반복 어휘 | 틀려도 의미 전달이 흔들리지 않음 |
| **텍스트 유형** | **말의 단위** | 짧은 문장 나열 | **문단** — 주제문 + 근거 + 마무리 |

### 여기서 제일 중요한 건 마지막 줄이다

`텍스트 유형`이 IM과 IH를 가른다. 나머지 셋이 좋아도 문장만 나열하면 IM에서 멈춘다.
반대로 문법이 좀 틀려도 **문단으로 말하면 IH가 나온다.**

## 4. IM1 → IM3 / IH 로 가는 실제 액션

| 지금 하는 것 | 바꿀 것 |
|---|---|
| 답변이 30~50초에 끝남 | **1분 30초** 채우기 — 시간이 곧 언어 샘플의 양 |
| 문장 하나 = 아이디어 하나 | 문장을 `because` / `so` / `which is why` 로 **묶기** |
| 전부 현재형 | 과거 경험 → **과거형**, 앞으로 계획 → **미래형** 을 한 답변 안에 섞기 |
| 모르면 침묵 | 필러로 시간 벌고 **아는 얘기로 방향 전환** |
| 답변마다 새로 생각함 | **만능 스토리 3개**를 어디든 붙임 (`01_템플릿/02_만능_스토리.md`) |

## 5. 자주 하는 오해

- ❌ **"어려운 단어를 써야 점수가 오른다"** → 아니다. 쉬운 단어로 **길고 구조 있게** 말하는 쪽이 높다
- ❌ **"대본을 완벽히 외우면 된다"** → 외운 티가 나면 오히려 감점 요인이고, 질문이 틀어지면 무너진다
- ❌ **"발음이 나빠서 IM1이다"** → 발음은 이해를 방해할 정도만 아니면 등급을 좌우하지 않는다
- ❌ **"실수하면 안 된다"** → 멈추는 것이 틀리는 것보다 나쁘다
