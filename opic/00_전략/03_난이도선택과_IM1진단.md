# 난이도 선택 + IM1이 나온 원인 진단

## 1부 — Self Assessment 난이도, 몇으로 고를 것인가

### 결론: **5단계**

| 난이도 | 나오는 문제 | 도달 가능 상한 (통상) |
|---|---|---|
| 1~2 | 단답, 아주 기초 | NM ~ IL |
| 3~4 | 일상 묘사, 습관 중심 | IL ~ IM2 |
| **5** | **묘사 + 경험 + 비교/설명 + 롤플레이 전부** | **IM3 ~ IH** |
| 6 | 5 + 추상적 이슈, 논증 요구 | IH ~ AL |

**왜 낮게 고르면 안 되는가.** 채점은 "내가 낸 언어 샘플"로만 이뤄진다.
난이도 3~4에서는 *비교하기, 문제 해결하기, 이슈 설명하기* 같은 문제가 잘 안 나온다.
그런 문제가 안 나오면 **IH 판정에 필요한 근거를 보여줄 기회 자체가 없다.** 상한이 생기는 것이다.

**왜 6은 아닌가.** 6은 추상적 사회 이슈("당신 나라의 주거 문제 변화를 설명하라")가 나온다.
IM1에서 출발하는 지금은 그 구간에서 무너져 오히려 감점된다. **5가 균형점**이다.

> 시험 중 2번 문제 뒤에 난이도를 조정할 기회가 온다. **그때도 5를 유지한다.**
> 어렵다고 낮추면 그 순간 IH 가능성이 사라진다.

## 2부 — IM1이 나온 원인, 이 중에 있다

시험을 다시 떠올리면서 해당되는 항목에 체크한다. **원인을 특정해야 4주가 안 낭비된다.**

### A. 길이 문제 (가장 흔함)
- [ ] 답변이 대부분 **1분을 못 넘겼다**
- [ ] 할 말이 떨어져서 "That's all." "That's it." 하고 끝냈다
- [ ] 남은 시간이 있는데도 다음 문제로 넘겼다

→ **처방:** 무조건 1분 30초. `01_템플릿/01_유형별_답변_템플릿.md`의 확장 기법으로 채운다.
   내용이 없으면 **이유를 붙이고, 예시를 들고, 반대 경우를 말한다.** 이 3개면 40초가 더 나온다.

### B. 구조 문제 (IM/IH를 가르는 지점)
- [ ] "I like X. X is fun. I do X on weekends." 처럼 **문장을 툭툭 던졌다**
- [ ] 문장 사이를 `and`, `also` 로만 이었다
- [ ] 답변에 **시작-중간-끝**이 없었다

→ **처방:** 모든 답변을 `주제문 → 이유 → 구체 예시 → 마무리` 4덩어리로.
   `01_템플릿/01_유형별_답변_템플릿.md` 를 몸에 붙인다.

### C. 시제 문제
- [ ] **과거 경험을 물었는데 현재형으로 답했다** ("Last year I go to Busan…")
- [ ] 답변 전체가 현재형이었다

→ **처방:** IH는 **과거·현재·미래를 다 다룰 수 있는지**를 본다.
   경험 문제가 나오면 의도적으로 과거형을 쏟아붓는다. `03_표현집/02_표현교체표.md` 참고.

### D. 대응 문제 (롤플레이·돌발)
- [ ] 롤플레이에서 **질문을 만들지 못했다** (질문하라는데 설명을 했다)
- [ ] 서베이에 없던 주제(날씨·교통·은행 등)가 나와서 얼어붙었다
- [ ] "I don't know" 또는 "Sorry, can you repeat" 로 넘긴 문제가 있다

→ **처방:** 롤플레이는 **공식**이 있다 (`01_템플릿/03_롤플레이_공식.md`).
   돌발은 **아는 얘기로 끌고 오는 기술**로 푼다 (`02_스크립트/08_돌발주제.md`).

### E. 유창성 문제
- [ ] 말하다가 **한국어가 튀어나왔다**
- [ ] "음…", "어…" 로 3초 이상 자주 멈췄다
- [ ] 같은 문장을 몇 번씩 고쳐 말했다 (self-correction 반복)

→ **처방:** 침묵을 **영어 필러로 대체**한다. `03_표현집/01_필러와_연결어.md`.
   틀린 문장은 **고치지 말고 그냥 다음 문장으로 간다.** 고치려다 멈추는 게 더 감점이다.

## 3부 — 진단 결과 기록

체크가 가장 많이 몰린 구간:

```
내 주 원인:  A / B / C / D / E   (동그라미)

구체적으로:
1.
2.
3.
```

**4주 플랜에서 이 구간에 시간을 더 준다.**
대부분의 IM1은 **A + B** 다. 그렇다면 어휘 공부는 뒤로 미루고, **길이와 구조**만 4주 내내 판다.
그것만으로 IM3는 나온다.
