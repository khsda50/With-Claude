## 작성 원칙

1. **한국어로 먼저 말하고, 그다음 영어로 옮긴다.** 영어부터 쓰면 아는 단어에 맞춰 이야기가 납작해진다
2. 모든 스크립트에 **"예상 밖의 일" 하나**가 들어가야 한다. 그게 있어야 과거형이 살고 1분 30초를 넘긴다
3. 전문 용어 금지. 특히 직장 스크립트 — 채점자는 반도체를 모른다
4. 완성 후 **대본 없이 녹음**해서 확인한다. 읽어서 되는 스크립트는 시험장에서 안 나온다
