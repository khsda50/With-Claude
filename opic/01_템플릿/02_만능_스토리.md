# 만능 스토리 3개 — 어떤 질문에도 붙이는 카드

## 왜 필요한가

시험에서 진짜 위험한 순간은 **질문을 이해했는데 할 말이 없을 때**다.
그때를 위해 **어떤 주제에도 갖다 붙일 수 있는 개인 스토리 3개**를 미리 만든다.

스토리 하나를 여러 문제에 재사용하는 건 감점이 아니다. 오히려 **디테일이 살아 있는 같은 이야기**가
매번 새로 지어낸 얕은 이야기보다 점수가 높다.

## 스토리 A — "친구랑 갔던 그날"  (여가 · 경험 · 롤플레이 전부 커버)

**뼈대 (영어로 채워 넣을 것):**

```
언제:  A couple of months ago, on a Saturday
누구와: my close friend from college
어디서: 
무슨 일이 있었나: 계획대로 안 됐다  ← 반드시 "예상 밖의 일"을 넣는다
그때 감정: 
어떻게 끝났나: 결국 더 좋았다 / 웃긴 기억이 됐다
```

**쓸 수 있는 질문들:**
- 기억에 남는 영화/공연 경험 → 그날 본 게 그 영화였다고 하면 끝
- 카페/음식점에서 있었던 일
- 예상치 못한 일이 생긴 경험 (돌발 문제 단골)
- 롤플레이 3번 문항("비슷한 경험을 말해보세요")

## 스토리 B — "요즘 빠져 있는 것"  (취미 · 습관 · 변화 커버)

**뼈대:**

```
무엇:  (음악 / 특정 아티스트 / 특정 장르 / 걷기 등)
언제부터: I got into it around last year, because …
계기:  (일이 힘들어서 / 친구 추천으로 / 우연히)
지금 하는 방식: 평일엔 이렇게, 주말엔 이렇게
예전과 달라진 점: I used to …, but these days I …   ← 비교 문제 자동 대응
앞으로: I'm planning to …
```

**쓸 수 있는 질문들:**
- 좋아하는 것 / 왜 좋아하는지
- 습관·빈도 질문
- **비교·변화 고난도 문항** (`used to` 문장이 이미 들어 있으므로)

## 스토리 C — "일 때문에 힘들었던 시기와 회복"  (직장 · 스트레스 · 휴가 커버)

당신은 실제로 검증 엔지니어다. **일 얘기는 이미 머릿속에 내용이 다 있다.**
영어 문장만 얹으면 되는, 가장 강력한 카드다.

**뼈대:**

```
상황: 프로젝트 마감 / 버그 하나가 안 잡히던 시기
왜 힘들었나: 원인을 못 찾아서 며칠을 썼다
어떻게 풀었나: 파형을 다시 봤더니 전혀 다른 곳이 원인이었다
그때 배운 것 / 감정:
그 뒤로 뭐가 달라졌나: 퇴근하고 걷기 시작했다 / 주말엔 일 생각 안 한다
```

**쓸 수 있는 질문들:**
- 직장 관련 콤보 전체 (하는 일 / 어려운 점 / 기억에 남는 프로젝트)
- 스트레스 해소 방법 (돌발 단골)
- 휴가·여가가 왜 중요한지
- 롤플레이 "문제가 생겼다" 문항의 배경

## 사용 규칙

1. **한 시험에서 같은 스토리를 두 번까지만** 쓴다. 세 번은 티가 난다
2. 붙일 때는 **연결 문장**을 앞에 둔다:
   - "Actually, this reminds me of something that happened to me."
   - "There's actually one time that always comes to mind when I think about this."
3. 스토리는 **한글로 먼저 완성**하고, 그다음 영어로 옮긴다.
   영어부터 쓰면 아는 단어에 맞춰 이야기가 납작해진다
4. 세 스토리 모두 **"예상 밖의 일"** 을 하나씩 품고 있어야 한다.
   그게 있어야 과거형이 살아나고, 답변이 1분 30초를 넘긴다
