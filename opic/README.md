# OPIc — IM1 → IM3/IH 4주 프로젝트

> 시작: IM1 · 목표: **IM3 이상, 가능하면 IH** · 기간: 4주 · 하루 30~60분

---

## 0. 먼저 알아야 할 것 하나

IM1과 IH를 가르는 건 **영어 실력이 아니라 말의 단위**다.

| 등급 | 말하는 단위 | 실제로 들리는 모습 |
|---|---|---|
| IL | 단어 · 구 | "Movie… I like movie. Action." |
| **IM1** | **짧은 문장 나열** | "I like movies. I watch movies. It is fun." |
| IM3 | 문장이 여러 개, 이어짐 | "I usually watch movies on weekends because weekdays are too busy." |
| **IH** | **문단** | 주제문 → 근거·예시 → 마무리. 과거·현재·미래 시제가 섞이고, 예상 못 한 질문에도 대응 |

즉 목표는 **어려운 단어를 외우는 게 아니라, 한 답변을 "문단"으로 만드는 것**이다.
IM1을 받았다는 건 문법이 부족해서가 아니라 답변이 "문장 3~4개 던지고 끝"이었을 확률이 높다.

**이 폴더 전체가 그 한 가지를 훈련한다.**

## 1. 폴더 사용법

| 폴더 | 언제 보나 |
|---|---|
| `00_전략/` | **1주차 첫날에 전부 읽는다.** 서베이/난이도 선택은 여기서 끝낸다 — 시험 점수의 30%는 이 선택에서 결정된다 |
| `01_템플릿/` | 매일 본다. 모든 답변의 뼈대. **여기가 핵심이다** |
| `02_스크립트/` | 서베이 항목별 실제 답변. 외우는 게 아니라 **내 것으로 고쳐 쓴다** |
| `03_표현집/` | 말이 막힐 때, 표현을 업그레이드할 때 |
| `04_플랜/` | 4주 일정표. 오늘 뭘 할지 모를 때 |
| `05_기록/` | 매일 녹음하고 로그 남기기. **이걸 안 하면 4주 뒤에도 IM1이다** |
| `tools/drill.py` | 랜덤 문제 출제기. 실전 연습용 |

## 2. 4주 지도

```
1주차   전략 확정 + 자기소개/직장/집 스크립트   → "문단으로 말하기" 감각 잡기
2주차   여가·취미 스크립트 + 롤플레이 공식      → 콤보 3종 세트 대응
3주차   돌발 질문 + 비교/이슈 (고난도 문항)     → IH 판정 구간 훈련
4주차   전체 모의고사 3회 + 약점만 반복         → 실전화
```

상세는 `04_플랜/4주_플랜.md`.

---

## 3. 매일 하는 것 (30분 최소 루틴)

1. **녹음 켠다** (휴대폰 녹음 앱). 안 켜면 훈련이 아니다
2. `tools/drill.py` 로 오늘 문제 3개 뽑는다
3. 각 문제를 **1분 30초** 답한다. 대본 없이, 중간에 멈춰도 끝까지
4. 녹음을 **다시 듣는다** ← 가장 고통스럽고 가장 효과 있는 단계
5. `05_기록/연습로그_템플릿.md` 에 오늘 막힌 지점 3줄 기록
6. 막힌 표현을 `03_표현집/` 에서 찾아 스크립트에 반영

> 규칙: **대본을 보고 말하는 연습은 하루 10분까지만.** 나머지는 전부 대본 없이.
> 대본을 완벽하게 외운 사람이 IM2에서 멈추는 이유는, 시험장에서 질문이 조금만 틀어져도 무너지기 때문이다.

---

## 4. 4주 뒤 시험장에서 지켜야 할 3가지

1. **한 문제에 최소 1분 30초.** 짧으면 채점할 언어 샘플 자체가 부족하다
2. **모르는 질문이 나와도 절대 "I don't know" 로 끝내지 않는다.** 돌려서 아는 얘기로 간다 (`03_표현집/01_필러와_연결어.md`)
3. **완벽한 문장보다 이어지는 문장.** 문법 틀려도 계속 말하는 쪽이 등급이 높다
